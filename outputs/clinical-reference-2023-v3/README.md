# 病毒性角膜内皮炎临床速查 · 彩色分区版 v3

依据《中国病毒性角膜内皮炎诊疗专家共识（2023年）》；p 为刊内页码，PDF 页码 = p−12。

## 下载与使用

| 文件 | 用途 |
| --- | --- |
| clinical_slides_color_v3.pptx / .pdf | 8 页可编辑彩色 PPT / 预览 PDF |
| clinical_algorithm_color_v3.pptx / .pdf | 一页彩色诊疗流程图，可编辑 / 打印 |
| A6_cards_color_v3.pptx / .pdf | 彩色 A6 双面速查卡，可编辑 / 打印 |

| slides_preview.png、card_color_*_preview.png | 快速查看外观 |

蓝色对应诊断、青色对应检查、橙色对应治疗、紫色对应随访/特殊人群、红色对应风险/停药提醒。颜色用于导航，不代表共识未给出的推荐等级或危险分层。板块有标题与边框，黑白版本可独立识别。

保留 v2 的文字、剂量、单位、阈值、引用页码、备注和页数；仅调整颜色、标题层级、板块底色和边框。所有 PPTX 使用原生可编辑文字、表格、线条和图形，没有页面截图。content_validation.json 记录逐页原文比对，render_validation.json 记录全部文本块与 PDF 的比对及 PPT Master 交付检查结果。

PPTX 使用微软雅黑（Microsoft YaHei）和 Arial 上标符号，字体未嵌入；请优先在 Windows PowerPoint/WPS 中编辑。云端缺少微软雅黑，PDF 导出输入明确指定完整 Noto Sans CJK SC 字体，并检查每个中文字串均使用 CJK 字体；已检查渲染、全部文本块和页数。尚未在用户的 Windows/WPS 客户端实测。

## 打印

优先使用 PDF。A6 为 105×148 mm，双面各一页；A4 为 210×297 mm，每面四张同内容 A6 卡。选择实际大小 100%，关闭自动缩放，纵向，双面长边翻转，先试印一张。A4 沿中间竖线与水平虚线裁切；普通打印机非打印区可能遮住边缘裁切线，请按 105×148 mm 尺寸裁切，正文有安全边距。

日常黑白打印使用 A4_cards_bw_editable_v3.pdf；彩色打印使用 A4_cards_color_editable_v3.pdf。A6 正文保持 9.5 pt；颜色不替代文字判断。
