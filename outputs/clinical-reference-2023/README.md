## 下载与编辑

如果从 GitHub 获取，请打开文件页面并选择 **Download raw file（下载原始文件）**，或下载上述 ZIP 后解压。不要把 GitHub 网页另存为 PPTX，也不要更改 PDF 的扩展名。

在 PowerPoint/WPS 中使用“文件 → 打开”选择下载的 PPTX。若软件显示“受保护的视图”，核对来源后选择“启用编辑”；这属于办公软件对下载文件的提示，文件本身没有设置编辑密码。点击幻灯片中的文字框或流程框即可修改。

PPTX 使用 Noto Sans CJK SC / Noto Sans 字体。字体缺失时软件可能替换字体；编辑后应检查换行和卡片边界。原始打印 PDF 已嵌入字体。

## 打印与来源核对

A6 卡片为 105 × 148 mm、正反各一页；A4 拼版为 210 × 297 mm、正反各四张卡。使用 **100% 实际大小、黑白或灰度、双面长边翻转**，先试印一张。具体边缘和裁切说明见 [print_instructions.txt](print_instructions.txt)。

每条关键建议标注 2023 年及期刊印刷页码（原 PDF 第 1–7 页对应期刊 p13–19）。剂量、单位、阈值按原文摘录；原文缺项注明“原文未明确”。单篇研究转述与共识建议分别标注。详见 [clinical_notes.md](clinical_notes.md)。
