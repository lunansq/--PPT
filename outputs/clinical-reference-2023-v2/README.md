# 病毒性角膜内皮炎临床速查 · 第 2 版

依据《中国病毒性角膜内皮炎诊疗专家共识（2023年）》；共识刊内页码 p13–19。

## 文件

- clinical_slides_8pages_v2.pptx：8 页中文 PPT；文字、图形和流程箭头可编辑。
- clinical_slides_8pages_v2.pdf：新版 PPT 的预览。
- clinical_algorithm_editable_v2.pptx：一页可编辑诊疗流程图。
- A6_cards_editable_v2.pptx：A6 双面卡可编辑稿。
- A4_print_layout_editable_v2.pptx：A4 拼版可编辑稿。
- clinical_algorithm.pdf、A6_double_sided_cards.pdf、A4_print_layout.pdf：已核对的流程图与黑白打印文件。
- evidence_and_proposed_flow.md/.pdf、evidence_table.csv、clinical_notes.md：提取表、拟定流程及证据说明。

## 本次修正与校验

使用官方 PPT Master v6.7.0 的原生 PPTX 工作流重新导出。明确设置中文字体 Microsoft YaHei（微软雅黑），上标 ⁹ 使用 Arial，并修正主 PPT 中 3 个重复对象编号。没有将文字或流程图转成图片。

逐页比对原版和新版 PPT 的全部文字及备注，剂量、单位、阈值、年份和原文页码保持一致；所有对象编号唯一。四份 PPTX 均通过交付检查，已在云端 LibreOffice 渲染检查。content_validation.json 记录内容校验结果。

字体没有嵌入 PPTX；请优先使用安装有微软雅黑和 Arial 的 Windows PowerPoint/WPS。其他平台可能替换字体。尚未在用户的 Windows/WPS 客户端实测。PDF 中中文字体已嵌入。

## 使用

下载 .pptx 后在 PowerPoint/WPS 中打开编辑；PDF 用于预览与打印。打开 ZIP 后先解压再使用。关键建议带 2023 年及刊内页码；未说明事项标为“原文未明确”，单篇研究发现与共识推荐分列。

A4/A6 打印方法见 print_instructions.txt。打印优先使用已核对的 PDF，实际大小 100%，黑白，双面长边翻转。
