# 干眼患者睑缘管理流程图：原图2彩色重绘

依据《中国干眼患者睑缘管理专家共识（2025）》原图2制作，2026年刊载，原刊p107（上传PDF第3页）。来源DOI：10.3760/cma.j.cn115989-20250712-00228。

保留原图8个疾病分支、三组分类、体征、诊断、治疗选项、箭头关系及留白；仅调整颜色、字体与间距，不是先前六节点摘要流程。前部睑缘炎为蓝色，后部睑缘炎为青绿色，睑缘结构异常为紫色。

| 文件 | 用途 |
| --- | --- |
| lid_original_fig2_color.png | 高清彩色预览 |
| lid_original_fig2_color.pdf | 单页PDF，便于阅读与打印 |
| lid_original_fig2_color_editable.pptx | 单页可编辑PPT；文字、框及连接线均为原生对象 |
| validation.json | 来源与文件检查记录 |

治疗各行按原图保留为对应选项，不添加物理→药物→手术的序贯箭头；空白单元格保留原图未列项。图中没有新增剂量、疗程或阈值。小字已逐框核对，包括“秃睫倒睫”“眼膏类厚涂”“睑缘融合等手术”。

解压后用PowerPoint或WPS打开PPTX进行编辑。PPT中文采用Microsoft YaHei，PDF嵌入完整中文显示所需字形；不同电脑可替换为本机完整中文字体。建议横向大纸幅阅读打印，缩放至A4时可放大查看细字。
