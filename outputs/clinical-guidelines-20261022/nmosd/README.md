## 原文缺项及重要核对事项

- 原文诊断表沿用2015 IPND标准；本文为2025版指南。引用年份应写2025，不能把诊断表误写为2025新标准。
- MRI附加条件严格保留“>3个连续椎体节段”和“>1/2视神经长度”；不改为≥。
- 硫唑嘌呤正文p697为2–3 mg·kg⁻¹·d⁻¹，表6 p695为2.5–3.0 mg·kg⁻¹·d⁻¹；两处差异并列保留，处方需回查。
- 利妥昔单抗表6与正文列有不同方案，不拼接为一个推荐方案；本文属超适应证经验疗法。
- AQP4-IgG随访频率p694建议每6个月，p698综合管理写每6–12个月；两处均保留；滴度与疾病活动无明确相关。
- p696“12周岁以上儿童及成人”按原文保留，未改写成≥12岁；本文未给完整儿童急性治疗体重剂量，不将成人1 g用于儿童。
- p698妊娠复发可用IVIG，但p694对急性视神经炎不推荐IVIG；两处适用情境不同，妊娠伴视神经炎须神经免疫/产科联合评估，不能从摘要自动得出处方。
- 原文未明确统一危险分层评分、临床转诊具体时限、所有药物儿童/肾肝功能调量表及哺乳期安全表，均不补编。
- 瑞利珠正文给剂量范围但未给体重区间对应剂量；原文已获批国内清单只明确萨特利珠、伊奈利珠、依库珠，不扩写瑞利珠国内批准状态。
- 三种已获批药物不是所有患者通用首选；须考虑抗体状态、合并症、感染风险、妊娠、可及性及个人偏好。
- 简明卡片的诊断为压缩摘要，尤其阴性/未知的完整MRI和临床标准须查提取表及原文；卡片不替代完整处方和专科评估。
